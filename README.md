# Coffee Heaven — Persian RTL Café Website Prototype

نسخه اولیه رابط کاربری کافی‌شاپ با الهام از تصویر مرجع.
- فارسی و RTL
- Responsive
- صفحه خانه
- صفحه منو
- صفحه سرویس بیرون‌بر و سبد سفارش
- صفحه وبلاگ
- صفحه نظرات و پیشنهادات
- صفحه ارتباط با ما
- صفحه عمومی منوی دیجیتال برای QR Code

## اجرا
فایل `index.html` را با مرورگر باز کنید.
برای نسخه واقعی، در مرحله بعد Backend/API، دیتابیس، احراز هویت مدیریت و درگاه پرداخت اضافه می‌شود.

## ساختار
- assets/: تصاویر و آیکون‌ها
- css/style.css: استایل اصلی
- js/app.js: داده محصولات، سبد خرید و رفتارهای عمومی
- pages/: صفحات داخلی
- digital-menu.html: صفحه مخصوص اسکن QR
